# ADR 001: модульный монолит

Статус: принято.

Контекст: completion меняет участие, навыки, ledger и версии; импорт связывает несколько каталогов с baseline. Нужны понятные транзакционные гарантии и воспроизводимый запуск на стартовом объёме.

Решение: один NestJS API, одна PostgreSQL, бизнес-модули с публичными application contracts, wiring в Nest-модулях. Domain/application независимы от фреймворка. HR использует read-only infrastructure projections.

Последствия: атомарность без Redis/Kafka/очередей. Владение данными и architecture tests ограничивают сцепление. Выделение сервисов требует отдельного обоснования и согласованности.
