# QCareer — Vue-фронтенд

Полный перенос `Career_Quest_Halyk_Pack/Career_Quest_demo.html` и связанных экранов из `02_prototype` на **Vue 3, Nuxt 4 и Tailwind CSS**. Сохранены светлая зелёно-золотая палитра, размеры, сетка и компоненты дизайн-пакета. Бренд — QCareer с собственным знаком Q.

## Запуск

Требуется Node.js 22.12+ (проверено на Node 24).

```bash
cd qforce_base/frontend
npm ci
npm run dev
```

После установки зависимостей приложение запускается одной командой `npm run dev`. Адрес — http://localhost:3000. Backend для локального демо не нужен.

```bash
npm test           # 38 проверок исходной бизнес-логики
npm run build      # production-сборка Nuxt
npm run preview    # локальный просмотр сборки
```

## Структура

- `app/pages/` — Vue SFC для каждого маршрута.
- `app/layouts/` — оболочка приложения и страницы входа/регистрации.
- `app/components/Cq*.vue` — повторно используемые карточки, уведомления, метрики, диаграмма, навыки и навигационные элементы.
- `app/composables/useCareer.js` — реактивное состояние, цель, план, завершение, импорт, HR-агрегация и сохранение.
- `app/utils/engine.js` — исходная детерминированная логика пакета, перенесённая из глобального IIFE в ES-модуль. Проекция профиля переиспользуется при подборе, чтобы не считать её отдельно для каждого события.
- `app/utils/labels.js`, `pages.js`, `icons.js` — подписи, карта маршрутов и исходные SVG-иконки.
- `app/assets/css/design.css` — CSS исходного макета; `app.css` — Vue-состояния и адаптивные поправки. `tailwind.config.js` задаёт общие цвета; Tailwind utilities используются в компонентах. Preflight выключен для сохранения исходного вида.
- `app/data/` — копия исходных 200 профилей, 40 событий, 60 навыков, 32 матриц ролей и 2743 записей истории.
- `tests/engine.test.js` — 38 тестов правил из пакета, адаптированных к ES-модулям.
- `tests/fixtures/` — синтетические примеры успешного и отклоняемого импорта.
- `docs/` — исходные документы пакета по API, AI и сценарию защиты. Это предложения для будущего backend, а не реализованные endpoints.

Нет iframe, вставки приложения через `v-html`, глобального `document`-обработчика действий или ручной замены `innerHTML`. Данные выводятся Vue-интерполяцией; события обрабатываются через `@click`, `@submit` и `v-model`. Имеющийся `app/pages/main.html` не подключается приложением и оставлен как исходный файл пользователя.

## Реализованные границы

Это **готовый интерактивный фронтенд демо**, а не production HR-сервис. Как и в исходном пакете:

- рекомендации — многофакторный baseline по прозрачным правилам, **LLM не подключён**;
- вход и регистрация демонстрационные; корпоративного SSO, паролей и серверной авторизации нет;
- HR/сотрудник — режимы просмотра, не защита данных;
- изменения находятся в localStorage `qcareer-vue-v1`, только в этом браузере;
- новые демо-профили получают начальные навыки по матрице текущего грейда; это не оценка человека;
- `/loading`, `/error` и `/forbidden` — отдельные макеты состояний;
- `qforce_base/backend` не менялся и пока не подключён. Предлагаемый контракт интеграции находится в `docs/API_AND_DATA.md`;
- исходная бизнес-дата — 2026-10-01, не дата системных часов. Дата записи self-paced в исходной истории — приближение даты завершения, как описано в пакете;
- регистрация и профиль не отправляют данные наружу. Датасет по ТЗ нельзя публиковать за пределами хакатона.
