# Карта экранов Vue

Актуальная таблица исходных hash-переходов и маршрутов Vue находится в `../README.md`, раздел «Экраны и переходы».

Все 20 экранов `Career_Quest_Halyk_Pack` перенесены. Дополнительно добавлены `/register`, `/screens` и fallback для неизвестного адреса. В приложении откройте `/screens` для обзора.

`event` и `completion` принимают `?id=EV_005`, `hr-employee` принимает `?id=E0028`. Если ID не передан, используется текущий выбор в демо. Неизвестный ID показывает отдельное пустое состояние.

Это Vue/Nuxt-фронтенд с локальным состоянием. Состояния загрузки, ошибки AI и отказа доступа остаются макетами; реальные LLM, SSO и серверные роли не подключены.
