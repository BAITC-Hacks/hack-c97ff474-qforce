## Результат слияния

Один словарь поддерживает Deutsch, English, Русский, 简体中文, Қазақша, Português и Español: 869 ключей. Сохранены переводы удалённой версии и новые тексты исправленных экранов. Выбор языка хранится между посещениями, синхронизируется между вкладками и имеет приоритет над языком профиля. Страницы не перемонтируются при переключении: введённые credentials и выбранные файлы импорта остаются на месте.

API получает `ru`, `kk`, `en`; для `de/zh/pt/es` используется `en`. Если сохранённого набора на выбранном языке нет, интерфейс читает последний сохранённый набор и переводит его подтверждённые факторы. Смена языка не генерирует рекомендации, не вызывает LLM и не записывает бизнес-данные.

Сохранены исправления предыдущего аудита: HR-подбор для импортированного профиля, просмотр событий без действий от имени сотрудника, независимые optional-блоки и retry, защита от поздних ответов другой сессии/профиля, состояния неполных данных, последовательные шаги и корректный прирост. Перевод объяснений учитывает новые поля истории, прерывания, критичность и итоговый уровень навыка; старые сохранённые объяснения также поддерживаются. Имена людей и идентификаторы отображаются без перевода, отчёты импорта сохраняют исходную диагностику.

Поиск ключей перевода и статусов защищён от наследуемых свойств `constructor`/`__proto__`. Сохранён единый словарь `frontend/app/locales/messages.json`; прежняя отдельная копия KK удалена после проверки отсутствия её использования.

README объединяет описание продукта из GitHub с проверенными настройками полного набора, OpenAI и отдельного fixture-окружения для браузерных тестов. Backend, данные, Compose и CI-исправления относительно `2f8d264` не изменены.
